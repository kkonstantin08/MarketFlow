# Журнал решений

Записи BOOTSTRAP предварительные до согласования спецификации. При изменении принятого решения добавляй датированную запись со ссылкой на заменяемую и обновляй затронутые документы.

| Дата | Проблема | Решение | Причина | Альтернативы |
| --- | --- | --- | --- | --- |
| 2026-11-09 | Где разместить API, логику и хранение? | Один API на .NET 10, один PostgreSQL, один проект xUnit. EF Core с Npgsql для обычного доступа к данным. | Мало компонентов и одна граница транзакции. | Раздельные проекты слоёв добавят связность и настройку. Микросервисы усложнят запись и запуск. |
| 2026-11-09 | Как защитить остатки от гонок и частичной записи? | Хранить одну строку на пару. Использовать условное атомарное обновление и прибавление через upsert. Записывать факт, остаток и журнал одной транзакцией. | База решает конфликты и обеспечивает атомарность между экземплярами API. | Блокировка строки с чтением требует дополнительных шагов. Serializable требует обработки повторов. Пересчёт всего журнала усложнит запрос остатков. |
| 2026-11-09 | Как распознать повтор приёмки? | Уникальный нормализованный номер поставки. Один номер на товар и склад. Точный повтор возвращает исходный факт, изменённый запрос получает конфликт. | Проверка уникальности работает и при параллельной записи. Одной позиции хватает для базового сценария. | Заголовок с отдельным ключом требует дополнительного протокола. Документ из нескольких позиций требует модели строк и правил их атомарной записи. |
| 2026-11-09 | Как трактовать резерв? | Резерв увеличивает зарезервированное количество и остаётся активным. В MVP нет снятия, срока действия и отгрузки. | Достаточно для проверки доступности без моделирования заказа и жизненного цикла. | Добавить отмену и TTL после подтверждения отдельного сценария. |
| 2026-11-09 | Как проверять запуск и поведение БД? | xUnit и тестовый PostgreSQL, Compose для локального запуска, GitHub Actions на Linux. | Тесты используют те же ограничения и блокировки, что приложение. | InMemory годится для простых проверок, но не воспроизводит конкурентные записи PostgreSQL. |
| 2026-11-09 | Какой интерфейс входит в MVP? | Открыто. Swagger UI входит в базовый технический контракт. Отдельный UI, стиль и подход ждут выбора владельца. | Это влияет на сроки и приёмку. | [Варианты исследования](design/research.md). |
